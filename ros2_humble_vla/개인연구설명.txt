  <h2 id="overview">1. 개발 개요</h2>
  <ul>
    <li><strong>목적</strong>: A6000 서버에서 VLA(ALOHA) 모델로 장애물을 감지하고, 내부 Wi-Fi를 통해 Raspberry Pi 기반 장치에 명령을 전달하여 실시간 경로 재탐색을 구현</li>
    <li><strong>기술 범위</strong>: ROS2 Humble, Gazebo/RViz2 시뮬레이션, Flask 서버, OpenCV, ALOHA 모델</li>
  </ul>

  <h2 id="environment">2. 개발 환경</h2>

  <h2 id="architecture">3. 시스템 아키텍처</h2>
  <pre><code>┌────────────────┐
│  UI Controller │
└───▲───────────┘
    │ Wi-Fi (HTTP/REST)
    ▼
┌──────────────────┐
│  Flask Server    │
└───┬───────────┬──┘
    │           │
    │ Wi-Fi     │ Wi-Fi
    │           │
┌───▼───────┐ ┌─▼───────────┐
│  CCTV Pi   │ │ TurtleBot Pi│
└───┬────────┘ └─────┬────────┘
    │                ▲
    │ 장애물 감지 이벤트
    └────────────────┘ (Flask 서버 통해 재명령)
  </code></pre>

  <h2 id="flow">4. 통신 및 제어 흐름</h2>
  <ol>
    <li>UI Controller → Flask 서버: 목적지 전송 (HTTP/REST)</li>
    <li>Flask 서버 → TurtleBot Pi: 주행 시작 (ROS2 토픽)</li>
    <li>CCTV Pi → Flask 서버: 장애물 감지 이벤트 전송</li>
    <li>Flask 서버 → TurtleBot Pi: 경로 재탐색 명령 전송</li>
    <li>TurtleBot Pi → Flask 서버 → UI Controller: 상태 보고</li>
  </ol>

  <h2 id="plan">6. 단계별 개발 계획</h2>
  <ol>
    <li><strong>환경 구축</strong>
      <ul>
        <li>ROS2 Humble 설치</li>
        <li>네트워크 설정 및 의존성 패키지 설치</li>
      </ul>
    </li>
    <li><strong>Flask API 개발</strong>
      <ul><li>목적지 전송 및 장애물 이벤트 엔드포인트 구현</li></ul>
    </li>
    <li><strong>VLA 모델 검증 및 설정</strong>
      <ul>
        <li>ALOHA 모델 다운로드 및 연동</li>
        <li>추론 속도·정확도 테스트</li>
      </ul>
    </li>
    <li><strong>시뮬레이션 세팅</strong>
      <ul><li>Gazebo/RViz2에서 TurtleBot 모델 및 장애물 배치</li></ul>
    </li>
    <li><strong>장애물 감지 로직</strong>
      <ul><li>CCTV Pi에서 OpenCV + ALOHA 모델로 감지 및 이벤트 전송 구현</li></ul>
    </li>
    <li><strong>경로 재탐색</strong>
      <ul><li>ROS2 Nav2 기반 실시간 좌표 업데이트 및 경로 계획 (ROS2 토픽)</li></ul>
    </li>
    <li><strong>통합 테스트</strong>
      <ul><li>전체 플로우 시뮬레이션 후 지연 시간 및 성공률 평가</li></ul>
    </li>
  </ol>

  <h2 id="objectives">7. 시뮬레이션 완료 목표</h2>
  <ul>
    <li><strong>정상 주행</strong>: 장애물 없이 지정 목적지까지 자율 주행</li>
    <li><strong>장애물 대응</strong>: 장애물 감지 후 5초 이내 재경로 탐색 및 주행 시작</li>
    <li><strong>성능 지표</strong>: 명령 응답 시간 &lt; 200ms, 경로 재탐색 성공률 ≥ 95%</li>
  </ul>
